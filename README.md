# Progree Internship DevOps Tasks

Welcome to my repository for the Progree Internship DevOps Tasks! 

This repository contains the completed solutions for all four assigned tasks, structured neatly into separate folders.

**Repository Link:** [https://github.com/danishcloudk/Progree-internship](https://github.com/danishcloudk/Progree-internship)

## 📋 Task Overview

1. **[Task 1: Professional LinkedIn Announcement](./Task-1-LinkedIn)**
   Contains the template and caption for the official internship acceptance LinkedIn post.
2. **[Task 2: Application Containerization & Asset Optimization](./Task-2-Containerization)**
   Contains a modular Node.js Express application and a multi-stage Dockerfile that securely maps environment variables and minimizes final image footprint.
3. **[Task 3: Multi-Stage Automated CI/CD Deployment Pipeline](./Task-3-CICD)**
   Contains an automated testing and integration workflow configured using GitHub Actions. It lints, tests, and builds the Docker image on remote pushes.
   * **Live Status:** [![CI/CD Pipeline](https://github.com/danishcloudk/Progree-internship/actions/workflows/ci-cd-pipeline.yml/badge.svg)](https://github.com/danishcloudk/Progree-internship/actions)
4. **[Task 4: Automated Infrastructure as Code & Orchestration Architecture](./Task-4-IaC-Orchestration)**
   Contains declarative Terraform configurations for AWS EKS provisioning and Kubernetes manifests for orchestration (Deployments, Services, Persistent Volumes, Ingress, and HPA).
